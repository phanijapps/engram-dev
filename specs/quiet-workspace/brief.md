# Quiet Workspace frontend

Make the current gate and its next eligible action easy to find.
Apply the owner-approved design to the existing spec library, Feedback tab and interview room.
Keep all existing routes, actions, APIs, stored records and gate rules.

Owners must still answer questions, approve the spec, accept decisions, grant Start permission and grant Finish permission as separate acts.
Feedback Save draft, Submit, Resolve and Reattach must remain separate operations.

Success means a quiet interface with readable status, stable action placement and accessible evidence.
The frontend must preserve blocked, unavailable, stale, conflict, audit-pending, empty and historical states.
The implementation must support the existing light and dark theme preference and narrow screens.

Exclude server changes, new screens, new endpoints, data migrations, agent wake-up, bulk approval and automatic owner actions.
