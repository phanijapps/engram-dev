# Overview

treadle is the harness, ported. One strict-TypeScript workspace holds
both planes the python engines taught: the loop (`do`) and the
knowledge (`know`), plus the two localhost surfaces and the golden
corpus that proves the port equals its teachers — byte for byte. [^t1]

The name is the architecture: the treadle is the pedal the weaver
works. The machine moves only when the human drives it; every write
path demands a `human:` claim. Formerly `loom`; the lineage stays in
the frozen packs. [^t2]

# The corpus: frozen witness model

The goldens were generated by the python engines and committed. The TS
generator (`gen_corpus.ts`) regenerates them from the TS engines — and
the diff is zero, byte for byte. `pnpm corpus:check` runs the TS
regeneration and gates on that diff. The python engines are
**retired** (tag `python-final`): equality with the frozen goldens
proved TS ≡ python, and the proof is permanent — the goldens are the
witness now. [^t3]

# The gates

`pnpm check` (tsc → eslint → prettier → 51 tests), `pnpm coverage`
(floors: 75 lines / 65 branches; tree at ~86/74), `pnpm brand:check`
(the name fence), `pnpm corpus:check` (self-hosted reproduction),
`pnpm audit:prod` (zero known vulnerabilities in the runtime chain).
CI runs the matrix on node 22/24 across linux/macos/windows. [^t4]

# What is deliberately absent

Tree-sitter code indexing: delegated to external tools (graphify
class) by owner decision — the knowledge engine owns the bundle, not
the code plane. MCP, templates, and the legacy spine are recorded
port-or-drop decisions. [^t5]
