# Path contract impact

| Surface | Disposition | Verification |
| --- | --- | --- |
| `do where` workspace and worktree scan | Revise: canonical root specs, legacy-only read fallback | Fixtures cover precedence, empty canonical root, legacy-only projects, and mixed worktrees |
| Closed specpacks and companion evidence | Relocate unchanged | SHA-256 equality for every inventoried file |
| Raw archives | Relocate to specs/archive; exclude from active discovery | Archive exclusion fixtures and relocation audit |
| Research | Consolidate full text in four current wiki concepts; original bytes in archive | Exact source text present in concept plus source hash preservation |
| Vendored OKF and schema | Relocate as wiki assets; OKF becomes .txt to avoid illustrative links becoming graph edges | Exact bytes and wiki validation |
| Replay and install guide | Relocate as wiki assets; replay evidence .md becomes .txt | Byte equality and HTML asset availability |
| Wiki sources and current root instructions | Retarget, with a migration note for prior dated source selectors | Source existence and line bounds; link checks |
| Historical findings, pack pins, and corpus strings | Retain | No content rewrite; old paths resolved by relocation inventory |
| Installed skill copies and server commands | Revise through installer/restart | Byte equality, discovery, GET endpoints, browser open result |

Root relocation is a path contract change, not a specpack or OKF format change.
Corpus outputs are frozen witnesses and retain illustrative historical strings.
